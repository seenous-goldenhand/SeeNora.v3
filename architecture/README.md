# معماری پیشنهادی SeeNora v3

این پوشه معماری SeeNora را به زبان ساده توضیح می‌دهد. پیشنهاد اصلی برای نسخه سوم چنین است:

- Desktop مرجع اصلی درخت تجهیزات و تاریخچه Measurementها باشد.
- Android به‌صورت Offline-first کار کند.
- درخت منتخب با HTTPS در شبکه محلی به موبایل منتقل شود.
- USB یک مسیر جایگزین برای کارخانه‌های بدون شبکه باشد.
- Raw Signal به‌صورت فایل ذخیره شود و دیتابیس فقط مشخصات و آدرس فایل را نگه دارد.
- برای MVP از PostgreSQL روی Desktop/Site و Room/SQLite روی Android استفاده شود.
- نسخه ویندوز با Installer و Windows Service منتشر شود. Docker برای سرور محلی تحت مدیریت IT مناسب‌تر است.

## تصمیم‌هایی که باید قبل از توسعه نهایی شوند

1. آیا هر کارخانه فقط یک Desktop مرجع دارد؟
2. انتقال شبکه‌ای فقط داخل LAN است یا از اینترنت همراه هم لازم است؟
3. آیا خروج Raw Signal از کارخانه مجاز است؟
4. حداکثر چند روز ممکن است موبایل آفلاین بماند؟
5. سیستم‌عامل قطعی Desktop و سرور کارخانه چیست؟

تا وقتی پاسخ دیگری داده نشده، فرض این مستند یک Desktop ویندوزی مرجع در هر کارخانه، شبکه محلی اختیاری و کار کامل موبایل بدون اینترنت است.
